# 对话区与输入框

## 对话区 {#the-thread}

对每个智能体，对话区都一样：

- **智能体说的话**，以 Markdown 显示。Mermaid 图表（` ```mermaid `）会以原生方式绘制；
  把 **设置 › 对话 › 数学公式** 设为 **排版为公式** 时，TeX（`$…$`、`$$…$$`、` ```math `）也一样。其中的链接：网址在你的浏览器中打开，`mailto:` 地址在你的邮件应用中打开，线程文件夹中的文件（以及随消息附上的文件）在右侧栏的查看器中打开；其他链接（应用、脚本、共享、其他应用的地址）不会打开，u0 会说明原因。查看器无法显示的文件只会在访达中显示，绝不会被打开。
- **工具调用**，每个一行，写明它做了什么：读取、创建、编辑、删除、移动、搜索、运行、获取、
  运行子智能体等等。展开一行可看到它的差异或输出。已结束的一轮中的调用会折叠成一行
  （“读取了 3 个文件，运行了 2 条命令…”）；仍在进行的一轮从不折叠。
- **计划**，显示已完成的步数，并提供 **复制计划** 和 **保存为文件夹中的 PLAN.md**。
- **权限卡片**：智能体在行动前提出的请求（“想要运行一条命令”、“想要编辑一个文件”、
  “提出了一个计划”），调用 u0 工具时还会显示其结构化参数。按钮是智能体自己的选项，
  默认是第一个“允许一次”的选项。**否，并告诉它…** 会在卡片内展开输入框，拒绝一次并发送该改做什么；
  **修改…** 会对计划发送修改意见；在卡片等待时直接在下方输入框发送消息，也会拒绝一次并发送你的消息。
  作答后，卡片会变成一行（“你允许了一次”）。⌘K 只提供等待中请求的“允许一次”选项；
  任何长期有效的选择都只能在卡片上做出，因此当智能体没有提供“允许一次”时，⌘K 会提供
  **查看等待中的请求** 并显示该卡片。
- **表单**：智能体请求输入时，对话区中会直接出现内联问题卡片，一次一个问题，你可以 **拒绝**，同时下方输入框保持可用。
- 智能体派去工作的**子智能体**（Claude Code 的 Task 和 Agent 工具，前台或后台）各是一张卡片，
  已结束的一轮折叠时也不会把它收起：写明它是哪种智能体、派给它的任务、**运行中**、**需要你处理**、
  **完成**、**失败** 或 **已停止**、用了多久、**打开对话**，运行时还有 **停止它**。卡片下方，
  它的调用像一轮的调用那样折叠成一行，展开后可看到它收到的任务和每个调用；再下面是它的回答。
  **打开对话** 显示它的完整记录，从派它工作的智能体给它的任务开始（“来自派它工作的智能体”）。
  正在工作或等待中的子智能体还会在对话区中显示汇总栏，并在上方获得标签页；× 会隐藏标签页，
  子智能体继续运行。从 Claude Code 载入的会话不带子智能体的用时，所以它们的卡片不显示用时。

### 记录视图 {#the-transcript-view}

⌃O 或标题的菜单可在五种视图间循环切换：

| 视图 | 显示 |
|---|---|
| 仅回答 | 你的消息和智能体的回答。 |
| 出错的调用 | 另外还有失败的调用。 |
| 普通（默认） | 每串调用折叠成一行，回答完整显示。 |
| 思考 | 另外还有智能体的思考过程。 |
| 详细 | 每个调用和步骤。 |

### 顶栏 {#the-top-bar}

标题旁，顶栏写出线程的项目、分支和它运行所在的服务器；线程等你回答时还有 **需要你处理**。
点按标题可重命名线程。它的菜单包含 **重命名**、**置顶**、**结清**、**延后…**、**并排打开**（并排显示两个线程，或在 ⌘K 中对线程按 ⇧Return）、**从这里分支新线程**、**新建侧边对话**、**复制线程链接**、**以只读方式共享给设备…**、**关联拉取请求…**、**标签…**、各种记录视图、**换用以下智能体继续**、**在编辑器中打开**、**归档** 和 **删除…**。

顶栏中间写着 **搜索线程、项目、命令和设置** 的框会在它下方打开命令面板，与 ⌘K 相同；顶栏空间不够时，只剩它的放大镜。
右侧，文件夹中有未提交的改动时，**提交 N 个文件** 会在差异标签页中打开提交表单；线程在这台 Mac 上时，**以只读方式共享这台 Mac…** 生成一个配对链接：配对的设备可以读取这台 Mac 上的每个项目和线程，而不只是这一个（与线程菜单中的 **分享只读链接…** 相同）；最后三个按钮显示或隐藏侧边栏、终端抽屉（⌘J）和右侧栏（⌥⌘B）。

### 查找 {#find}

⌘F 在线程中查找：Return 跳到下一个匹配，⇧Return 跳到上一个，Esc 关闭。
⌃⇧↑ 和 ⌃⇧↓ 在你自己的消息之间跳转。

### 轮次：撤销、恢复、分支 {#turns-undo-restore-branch-off}

每个回答上方有一行，写出智能体及其模型、这一轮用了多久以及你提问的时间；它的按钮可复制回答、在回复中引用它，或在它之后分支出新线程。

在 git 仓库中，u0 会在每一轮之前和之后为文件建立检查点（见
[工作树与检查点](worktrees-and-checkpoints.md)）。改了文件的一轮下方有一张卡片，列出这些文件及各自增删的行数；点按文件或 **在差异中显示** 会在差异标签页中打开这一轮的改动。当线程空闲时：

- **撤销**（最后一轮）或 **恢复到之前**（更早的一轮）会把文件恢复到这一轮之前的样子；
- **重做** 会把这一轮的改动放回去。

一次编辑自己的 **在差异中显示** 只显示这次编辑。

### 计划 {#plans}

智能体维护的计划会显示每一步已完成、进行中还是待做，以及完成了几步；可以复制它，或把它保存为文件夹中的 PLAN.md。在只做规划的模式中（按智能体列出的模式），最新的计划带有 **实施计划**：切换到智能体为工作列出的模式，并请它执行计划；以及 **继续规划**：把你带到输入框，此时输入框写着 **请求修改计划**。输入框上方的一行写出当前模式，以及打开模式的按键（⇧⌘A）。

在你的每条消息上：**从这里分支，重新说一遍**，以及 **回滚到这里**
（在文件可以随之回滚时，还有 **回滚到这里，文件也一起**）。

## 输入框 {#the-composer}

写下任务或问题，然后按 Return（改用 ⌘Return 见[设置](reference/settings.md#chat-and-composer)中的
`send`）。↑ 和 ↓ 可调出你之前发送过的消息。

### 标签 {#chips}

文本下方的标签显示并可更改消息所附带的内容：新建线程时的项目，以及在仓库中的 **工作树** 和它
**基于** 的分支；模型；模式；以及一个圆环，显示智能体的上下文已用了多少。

### 附件 {#attachments}

粘贴、拖入或选择文件和图片（**+ › 添加文件或照片**），或用 **添加窗口** 附上已打开窗口的截图（或直接在屏幕上点选）。
点击图片的缩略图可以查看原图，按 Esc 或点击外面关闭。HEIC 和非常大的图片会被转换为 JPEG。32 KiB 或更大的粘贴内容会成为附件（⇧⌘V 则作为文本粘贴），超过长度上限的消息提供 **作为文件附上**。
拖入的文件夹会被 @ 提及。**+ › 添加文件夹** 会给新线程另一个可工作的文件夹，前提是智能体支持。

### @ 提及 {#-mentions}

输入 `@` 可从项目中指名：一个文件、另一个线程（以其对话内容发送）、一个未关闭的拉取请求或议题，
或一个模型（会切换到该模型）。

### / 命令 {#-commands}

输入 `/` 可使用智能体自己的斜杠命令，以及 u0 的：`clear`、`usage-limits`、`model`、
`branch` 和 `copy`。

### 智能体工作时 {#while-the-agent-works}

在一轮进行中发送的内容默认会 **排队等待**：它进入队列，在这一轮结束时发送。队列中的每条消息都有
**提前**、**立即发送**、**编辑**（在输入框中原地编辑并 **保存到队列**）和 **从队列中移除**；⌥↑ 编辑最后一条。正在编辑的消息无论队列如何变化都保持在原位，在你保存或按 Esc 之前，队列不会发送它，也不会越过它。把 **设置 › 对话 › 你发送的内容排队等待，或引导当前一轮**
设为 **引导** 时，消息会改为引导正在进行的这一轮。⌘-点按“发送”或按 ⇧⌘Return，则按另一种方式发送。

**稍后再说**（时钟标签）会在 30 分钟、1 小时、3 小时后，明天 9:00，或每天 9:00 发送消息。
⌘S 把草稿留到以后。

开启 **设置 › 写作 › 建议下一步说什么** 后，每一轮结束时写作者会建议你的下一条消息：
Tab 采用，Esc 忽略。

### 拼写 {#spelling}

输入时，拼错的单词会加下划线，右键菜单中有系统给出的候选词。
**设置 › 对话 › 输入时检查拼写** 可将其关闭。

### 听写 {#dictation}

⇧⌘D 使用 Apple 的语音识别向输入框听写，只在这台 Mac 上进行。聆听时输入框显示听到的内容；
Esc 取消。**设置 › 语音** 可设置：

- **听写**：要识别的 **语言**；**听写键**（其 **更改** 会在快捷键中打开它）；**按键的工作方式**：
  **自动**（按一下开始、再按一下停止；按住时则一直聆听到你松开）、**切换** 或 **按住**；
  以及 **说话时显示文字**（关闭时输入框只显示正在聆听）；
- **清理**：**移除填充词**、要去掉的 **填充词**（um、uh、er、hmm…）；**更正提示语**
  （“scratch that”），会撤回你在它之前说的那句话；**由写作者整理**，以及在 **写作** 中选择的 **写作者**；
- **词典**：**你的词语**，听写会留意它们；写成 `heard = written` 的词会把听到的内容写成另一种写法。

**编辑 › 语音 › 开始朗读** 会朗读输入框中选中的文本，否则朗读智能体的最后一条回答。

## 模型与模式 {#models-and-modes}

⇧⌘M（或模型标签）打开模型选择器：左侧是 **收藏** 和各个智能体，中间是该标签的模型（每个附有智能体对它的说明，前九个旁标有 ⌘1–⌘9），
右侧是该智能体的选项（另一个智能体的标签显示它的线程开始时的选项，它尚未告知时则不显示；搜索时或在 **收藏** 中显示本线程自己的选项），标签下方是 **智能体设置**。在新建线程中，更改另一个智能体的选项会把线程换到那个智能体，与选择它的模型一样。正在启动、正在安装、尚未安装、启动失败或未登录的智能体会在它的标签上注明；需要你处理的智能体会在它的模型上方给出一个按钮（**智能体设置** 或 **登录**）；选择一个标签会清除搜索。
窗口较窄时，标签只显示智能体的标志。用 **搜索模型…** 在所有智能体中搜索，给模型加星以将其保留在收藏中，
并在智能体自己给它起的名字下（Codex 的 **Reasoning effort**）选择它思考的力度。智能体提供的速度选项（例如 Codex 的 **Fast mode**）是 **速度** 下的一个开关，
开启时思考力度标签旁会显示一个闪电；其他选项各是一行，点开是它的选项菜单。⇧⌘E 也会打开选择器。线程开始后，只提供该线程智能体的模型。
在新建线程中，点击任意模型旁的 **+** 可将其加入 **同时运行于**（**发送给全部 *n* 个智能体** 则添加所有可用智能体），为每个目标各自启动一个线程和一个工作树：添加目标会打开 **工作树**，关闭 **工作树** 则线程只用它自己的智能体，不在 git 仓库中时也只用一个，因此绝不会有多个智能体在同一个文件夹中工作；勾选 **在后台启动** 可在发送后留在新草稿页。

⇧⌘A 打开模式菜单：智能体的各种模式（例如只读、先询问、自动），按智能体列出的样子显示，
各带说明；⌘1–⌘9 可选择其一。

你自己的模型 ID 可以在智能体的页面上添加（见[首次运行](first-run.md#an-agents-page)）。
你在某个项目中为某个智能体最后做出的选择，就是它在该项目中下一个新线程的初始选择。

## 用量 {#usage}

⌘U 打开 **用量**：每个线程的花费和消耗的 token，可按智能体、按模型、按线程查看，范围为
24 小时、7、30 或 90 天，或全部（⇧⌘1 到 ⇧⌘5）。u0 自己不做任何计算：它显示的是智能体报告的数据。
**限额** 显示每项用量限额的当前状态以及何时重置，前提是智能体提供了这些信息（Claude 的适配器提供）。
因限额而停止的一轮会在限额重置时自动继续（见
[自动化](automation.md#when-a-usage-limit-stops-a-turn)）。

## 通知 {#notifications}

当线程结束一轮、失败或需要你处理，而 u0 不在前台时，macOS 会显示一条通知（见
[设置](reference/settings.md#notifications-and-background)中的 `notify` 和 `notify_on`）。
u0 在前台时，则改为在右上角显示一条通知。它几秒后自行消失（鼠标停在上面时会等着）；
说线程需要你处理的那条会一直留着，直到你回应。

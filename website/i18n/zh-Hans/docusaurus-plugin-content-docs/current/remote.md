# 远程控制

一台机器上的 Ghost 可以从别处的 Mac 使用：它的智能体、会话、文件、git
和终端，就像你坐在它面前一样。每个 Ghost 都能担任两种角色：

- **被控制**：允许其他设备控制这台 Mac（或运行 `ghost-server` 的 Linux 机器）；
- **控制**：在这个窗口中，把其他 Mac 与本机并列掌控。

两者都在 **设置 › 设备** 中，且默认都是关闭的。

## 设备如何接入 {#how-a-device-comes-in}

设备凭密钥接入，从不凭密码：

1. 配对时，控制方 Mac 会为那一台服务器生成一把 Ed25519 密钥。私钥留在它的钥匙串中，只发送公钥。服务器以其 `SHA256:` 指纹列出它。
2. 配对需要一个配对码：128 位随机数，只能使用一次，十分钟内有效，只保存在内存中（重启即失效）。
3. 此后桌面端每次建立连接时，服务器都会发送一个新的随机数（nonce），桌面端用它的密钥对其签名。没有任何秘密经过网络传输，也没有任何秘密存放在服务器上。

关闭监听会立即切断所有连接，并作废所有未使用的配对码。对某台设备点击 **撤销** 会删除它的密钥并关闭它的连接。

## 允许其他设备控制这台 Mac {#let-other-devices-control-this-mac}

在 **设置 › 设备** 中，打开 **允许其他设备控制这台 Mac**。（Ghost 菜单中的
**显示配对码…** 效果相同，并会打开该页面。）

此后 Ghost 只在 `127.0.0.1` 上监听，端口为 4317（即
`<home>/devices.json` 中的 `port`；同一台机器上的第二个 Ghost 请另设一个）。
网络上的任何东西都无法直接访问这个端口。设备可以通过以下两种方式之一访问它：

- **cloudflared 隧道。** 在 **访问方式 › 隧道（cloudflared）** 下，点击
  **启动**。Ghost 会运行你 `PATH` 中的 `cloudflared`（用
  `brew install cloudflared` 安装）。默认是快速隧道：每次启动都会得到一个新的
  `trycloudflare.com` 地址，因此设备必须用新链接重新配对。若要保持同一个地址，请使用你自己的命名隧道：
  输入它的主机名和隧道令牌，然后点击 **使用**。**使用快速隧道** 可切换回去。
- **SSH 端口转发**，在控制方 Mac 上执行：
  `ssh -L 4317:127.0.0.1:4317 host`，然后用 `127.0.0.1` 链接配对。

**提供服务时保持 Mac 唤醒** 让这台 Mac 在无人值守时也能被访问（Ghost
在监听期间运行 `caffeinate`）。

### 配对链接 {#the-pairing-link}

在 **将设备与这台 Mac 配对** 下，Ghost 会显示一个配对链接及其二维码：

```
ghost://pair?host=<host>#<code>
```

隧道开启时，host 是隧道的地址，否则是 `127.0.0.1:<port>`。该链接只能使用一次，十分钟内有效。**复制** 会复制它，**新链接** 会生成另一个。在另一台 Mac 上打开它、扫描它的二维码，或将它粘贴到那里。

### 控制这台 Mac 的设备 {#devices-that-control-this-mac}

每台已配对的设备都会列出它提供的名称、其密钥的指纹、配对时间以及最近一次连接的时间。**撤销** 会立即切断它。

## 控制其他 Mac {#control-other-macs}

打开 **控制其他 Mac**。然后在 **与另一台 Mac 配对** 下，粘贴另一台机器的配对链接并点击 **配对**。打开一个
`ghost://pair` 链接（从浏览器、扫描二维码或 `open`）效果相同。
Ghost 菜单中的 **配对设备…** 会打开控制功能并带你到那里。

Ghost 在配对前会询问你：它会给出主机名以及为该主机生成的密钥的指纹。

### 双向同时配对 {#both-ways-at-once}

确认框中有 **同时允许它控制这台 Mac**。勾选后，这台 Mac
开始监听，对方则凭这台 Mac 生成的一次性配对码，用它自己的密钥反向配对。如果对方本身是通过
`127.0.0.1` 被访问的，它就在 `127.0.0.1` 访问这台 Mac，否则只能通过这台 Mac 自己的隧道访问，而该隧道必须已开启。对方无法访问这台 Mac 时，配对保持单向，并说明原因。（当这台 Mac 的窗口运行在 launchd 服务上时，不提供该复选框。）

### 一个窗口中的多台 Mac {#several-macs-in-one-window}

打开控制功能后，你配对过的每台服务器都会与这台 Mac 一起出现在窗口中：

- 侧边栏为每台服务器显示一行（这台 Mac 排在最前），其下是它的项目和会话，以及它是否可访问。
- 新会话、⌘K 和 ⌘P 会标明每个项目所在的服务器。
- 设置对话框顶部有一个服务器选择器。某台服务器的智能体、项目、任务、共享设置以及它保存的内容，都从该服务器读取并保存在该服务器上。外观和按键仍属于这台 Mac。
- 需要终端的智能体登录，会在该服务器上的 Ghost 终端中进行。

**这台 Mac 控制的 Mac** 会列出它们，以及你的密钥指纹、各自运行的版本和状态：在此窗口中、正在连接、离线或被拒绝。**重新连接** 会立即重试；**忘记** 会移除该服务器，并从钥匙串中删除它的密钥。

### 连接断开时 {#when-a-link-drops}

断开的服务器会显示为离线，窗口中已有的内容仍可阅读，并会自动重新连接（先等待 1 秒，之后逐渐延长，两次尝试之间最长 30 秒）。服务器会保留它最近发出的 16 MiB 内容；回到同一次服务器运行的桌面端，会按顺序收到它错过的一切。服务器重启后，或错过的内容更多时，桌面端会重新读取全部内容。离线期间你所做的操作会在连接恢复后发送。拒绝了这台 Mac 的服务器不会被重试，直到你点击 **重新连接**。

## Linux 服务器 {#a-linux-server}

`ghost-server`（见[安装](install.md#on-linux-ghost-server)）启动时即开始监听，如果之前开启了隧道则启动隧道，并打印：

```
Ghost serves on ws://127.0.0.1:4317
Pair a desk with it, once, in the next ten minutes: ghost://pair?host=…
```

随后是该链接的二维码。通过隧道或 `ssh -L` 访问它，然后按上文所述从 Mac 配对。

## 文件 {#files}

| 文件 | 位置 | 内容 |
|---|---|---|
| `devices.json` | 在被控制的机器上 | 允许接入的设备（`label`、`key`（形如 `ssh-ed25519 AAAA…`）、`paired`、`seen`）、`port`，以及是否监听（`serve`）、是否运行隧道（`tunnel`）、是否保持唤醒（`awake`），和命名隧道（`named`：`{token, host}`）。 |
| `servers.json` | 在控制方 Mac 上 | 已配对的服务器（`name`、`host`、`key`：为其生成的密钥的公钥），以及 `control`。每把私钥都保存在钥匙串中的 `server/<fingerprint>` 下。 |

两者都拒绝未知字段。无法读取的文件会保持原样，在修复或移走之前，没有设备能够接入（`devices.json`），也没有服务器能被访问（`servers.json`）；移走后请重新配对。

:::caution

命名隧道的令牌以明文形式存储在 `devices.json` 中。

:::

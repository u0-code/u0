# 项目与线程

## 项目 {#projects}

项目就是一个文件夹。它不必是 git 仓库。

### 添加项目 {#adding-a-project}

- 从“访达”把文件夹拖到侧边栏上。
- **添加项目**（没有项目时在侧边栏中，也在 **项目** 弹出框中，或在命令面板 ⌘K 中）提供：
  - **选择文件夹…**；
  - **克隆仓库**，克隆到 `projects_in` 指定的文件夹
    （默认为 `~/Documents/u0`；设置了 `host_folders` 时，按
    `<host>/<owner>/<repo>` 排布）；
  - **新建项目**：在那里新建一个文件夹，并在装有 `gh` 时为它创建一个私有 GitHub 仓库；
  - 最多六个你的智能体已经工作过的文件夹。
- 输入以 `/` 或 `~` 开头的路径即可浏览：Tab 进入文件夹，⌘Return 添加你输入的路径，
  在空行上按 ⌫ 返回上一级。
- 在终端中：`u0 <folder>`（见 [CLI](reference/cli.md)）。
- 用 u0 打开指向某个文件夹的 `file://` 链接，会添加该文件夹并开始一个线程。

### 包含多个仓库的文件夹 {#a-folder-of-repositories}

本身不是仓库的项目文件夹可以包含多个仓库：直接位于其中的每个仓库，或再往下一层的仓库
（例如 `packages/web`），最多 128 个，不包括隐藏文件夹和子模块。
每个仓库都出现在“差异”标签页的仓库选择器中，各有自己的改动、提交、提交表单和拉取请求。
工作树线程会得到一个与项目结构相同的文件夹，其中每个仓库都有一个位于线程分支上的工作树，
其余内容则以链接方式放入；每一轮都会在每个仓库中建立检查点、撤销和比较差异。

### 项目设置 {#project-settings}

**设置 › 项目**（或项目菜单中的 **项目设置**）为每个项目保存：它的名称和图标、是否置顶、
新线程默认使用的智能体、新线程是否在工作树中工作、是否在 u0 启动时和每次 fetch 时拉取默认分支、
它的议题来自哪个 Linear 团队，以及少数几项与全局不同的设置（拉取请求如何合并、squash 时
对智能体的署名、子模块、按工作类型的分支名、额度重置后是否继续，以及是否删除已归档线程的工作树）。
见 [settings.json](reference/settings.md#projects) 中的 `prefs`。

移除项目不会动它的文件夹、工作树和文件。

## 线程 {#threads}

线程属于各个智能体，由智能体按项目列出。u0 为它见过的线程保存一份索引（标题、置顶、归档、
工作树），并为每个线程保存一份记录，因此列表和对话都能立刻显示。有记录的线程在你写入时
与智能体恢复（resume）；没有记录的线程（在别处开始的）则从智能体加载，并从此开始记录。

在终端里开始的线程会出现在它的项目中（u0 运行时每分钟重新询问各智能体，因此一分钟内出现），并可以接管：打开它，智能体加载时历史随之显示；加载完成后，像其他线程一样
在其中写入。智能体的 CLI 若说明它正在运行哪些线程（Claude Code 会），仍在另一个进程（例如
终端）中打开的线程会在侧边栏显示一个终端标记，并在输入框上方显示 **Claude Code 也在别处打开着此线程**：
你在 u0 中发送的内容在 u0 中继续，那个进程看不到。一次只在一处写，或 **分出一个副本** 各自继续。

### 侧边栏 {#the-sidebar}

- 所有项目中 **已置顶** 的线程排在最前，顺序按你拖动的顺序。
- 每个 **项目** 列出它尚未完成的线程。排序由设置中的 `sort` 决定：按你的最后一条消息（默认）、
  按任何活动、按开始时间，或按名称。
- **稍后提醒** 和 **已完成** 分组折叠在底部。
- 新线程在发送之前不会成为一行。每个项目保留一份草稿：项目上的 +、⌘N、⇧⌘N、⌥⌘N（草稿）和命令面板的
  **新建线程于…** 会把它按你离开时的样子带回来（你输入的、附加的和选择的），没有草稿时则新建一份。
  换成另一个智能体时，除模型和选项外都保留。为议题、拉取请求、失败的工作流步骤或链接里的提示词新建线程时，
  若草稿里已有内容，会先询问再替换。没有打开的线程时，起始页的输入框就是该项目的草稿，带着其中的内容；
  旁边从不会有第二份。

每一行末尾显示线程的状态：工作中、待批准、登录、失败、受限、计划、完成或已唤醒。

搜索框匹配标题、#标签、拉取请求编号、分支和项目；输入两个字符起，还会搜索每个线程中说过的内容。

列表中的按键：↑ ↓ → ← 移动和折叠；Return 或空格打开；F2 重命名；⇧F10 或右键打开菜单。
⌘-点按和 ⇧-点按可选中多行。按住 ⌘ 可看到 ⌘1–⌘9 跳转到的编号。把一行拖到已置顶的行上即置顶，
拖到“已完成”上即标为完成，拖到某个项目上即重新激活。

### 线程的菜单 {#a-threads-menu}

右键点按一个线程（或按 ⇧F10）：

| 菜单项 | 作用 |
|---|---|
| 重命名、重新生成标题 | 自己重命名，或让写作者重新起标题。 |
| 置顶 / 取消置顶 | |
| 标为完成 / 取消完成 | 标记为已完成，或取消。 |
| 稍后提醒 / 唤醒 | 隐藏到某个时间：`snoozes` 中的选项，或 **自定义…**（“in 3h”、“in 2 days”、“at 5pm”）。在其中写入内容会唤醒它。 |
| 标为未读 | |
| 在线程中查找 | |
| 按项目筛选、项目设置 | |
| 在 *分支* 上新建线程 | 在这个线程的分支上开始一个新线程。 |
| 分出一个副本 | 线程的一个副本，用来换条路走（在智能体支持分叉时）。 |
| 换用以下智能体继续 | 把线程交给另一个智能体。 |
| 复制 | 对话、路径、分支、链接或线程 ID。 |
| 永不自动标为完成 / 允许自动标为完成 | |
| 归档、删除 | 线程忙碌时不可用。 |

取消置顶、标为完成、稍后提醒、归档和删除会显示一条带 **撤销** 的通知，持续五秒；⌘Z 也能撤回。
删除前会先询问（见 `confirm`）；如果只有这个线程在用它的工作树，u0 会问是否一并删除工作树。

已归档的线程和项目在 **设置 › 归档** 中，可以 **恢复** 和 **删除**。

### 暂告一段落 {#done-for-now}

在以下情况下，线程会自动标为完成：

- 它已闲置 `settle_days` 天（默认 7 天）；
- 它的拉取请求已合并或关闭（`settle_merged`）。

置顶的线程、设为永不自动标为完成的线程，以及（开启 `keep_with_pr` 时）有未关闭拉取请求的线程，不会自动标为完成。

### 链接 {#links}

u0 可以打开 `u0://` 链接：

| 链接 | 作用 |
|---|---|
| `u0://new?project=…&agent=…&prompt=…` | 在你已有的项目中新建一个线程（带 `pr=` 或 `issue=` 时，关于该拉取请求或议题）。链接从不添加项目。 |
| `u0://session/<agent>/<id>?prompt=…` | 打开一个线程，并带上草稿。 |
| `u0://pair?host=…#…` | 与机器配对（见[远程控制](remote.md)）。 |

链接提示词中的不可见字符会被去掉，并告知你。会替换现有草稿的链接会先询问。
